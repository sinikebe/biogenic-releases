# Biogenic

A game of microscopic life: swim as a cell, feed, and shape its abilities through
genes.

This is Biogenic's public download repository. Game builds, update files, and
release notes live here; the game's source code does not.

## Try it in your browser

**[Play the dev browser demo](https://sinikebe.github.io/biogenic-releases/dev/)**

The browser version is a single-player demo of the current development build.
It has **not reached a release yet**, so only the dev demo is available. For
multiplayer, download the Android or Windows version below.

## Download

| Platform | Latest release | Development build |
| --- | --- | --- |
| Android | [Download APK](https://github.com/sinikebe/biogenic-releases/releases/latest/download/biogenic.apk) | [Download dev APK](https://github.com/sinikebe/biogenic-releases/releases/download/branch-dev/biogenic.apk) |
| Windows | [Download EXE](https://github.com/sinikebe/biogenic-releases/releases/latest/download/Biogenic.exe) | [Download dev EXE](https://github.com/sinikebe/biogenic-releases/releases/download/branch-dev/Biogenic.exe) |

- **Android:** open the APK to install it. On the first installation, allow
  “install unknown apps” for the browser or file manager opening the file.
- **Windows:** download and run `Biogenic.exe`; there is nothing to unpack.
- **Development builds** are works in progress. They install separately from
  the released app and keep their own saved data.

See the [latest release](https://github.com/sinikebe/biogenic-releases/releases/latest)
or the [rolling dev build](https://github.com/sinikebe/biogenic-releases/releases/tag/branch-dev)
for release notes and all files, including the Linux dedicated server and
`SHA256SUMS` download checksums. The Linux build is a server, not a desktop client.

## Updates

The downloaded game checks for updates on launch. Released apps receive release
updates; dev apps receive development updates. The browser demo is updated in
place, so there is nothing to install.
